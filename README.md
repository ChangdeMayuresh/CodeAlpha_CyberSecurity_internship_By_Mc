## 📌 Executive Summary
This repository showcases the practical projects and technical assessments completed during my **Cyber Security Internship** at CodeAlpha. The tasks focus on defensive security, threat detection, vulnerability remediation, and security awareness.

👤 **Author:** Mayuresh  
🎓 **Role:** Cyber Security Intern

---

## 💡 Core Competencies Developed
During this internship, I gained hands-on experience in:
- **Network Traffic Analysis:** Intercepting and analyzing live packets using Python and Scapy.
- **Threat Detection (IDS):** Configuring and deploying Suricata in containerized (Docker) environments.
- **Secure Code Review:** Identifying memory corruption vulnerabilities (Buffer Overflows) in C++ and applying safe coding practices.
- **Human-Centric Security:** Designing training modules to combat social engineering and phishing campaigns.

---

## 📂 Internship Projects Breakdown

| Project Folder | Domain | Description | Key Technologies |
| :--- | :--- | :--- | :--- |
| **`Task-1`** | Network Security | A custom packet sniffer built to capture and analyze TCP/UDP traffic in real-time. | `Python`, `Scapy` |
| **`Task-2`** | Security Awareness | A comprehensive training module designed to educate end-users on identifying social engineering tactics. | `Risk Management` |
| **`Task-3`** | Application Security | Manual code audit of a C++ program to identify, document, and remediate a CWE-120 Buffer Overflow vulnerability. | `C++`, `Code Auditing` |
| **`Task-4`** | Infrastructure | Deployment of Suricata IDS via Docker to monitor host network traffic and trigger alerts for custom ICMP rules. | `Suricata`, `Docker`, `Linux` |
